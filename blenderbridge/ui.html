Blender verbinden

  1. In Blender: Bearbeiten → Einstellungen → Add-ons → Installieren… und die Datei blenderbridge_addon.zip wählen.
  2. Add-on „BlenderBridge“ aktivieren.
  3. Im 3D-Fenster N drücken → Reiter BlenderBridge → Server starten.

Der Token wird automatisch zwischen Connector und Add-on geteilt (Datei im Konfigurationsordner). Falls die Verbindung nicht klappt, Token kopieren und im Add-on-Panel einfügen.

Agent-Schlüssel

Ein Agent braucht einen Schlüssel im Header Authorization: Bearer …. Schlüssel werden nur einmal angezeigt und gehasht gespeichert.

Relay (für Agenten ohne direkten Netzzugriff)

Manche Agenten können nur GitHub erreichen. Dann arbeitet der Connector als Postfach: Anfragen liegen als Kommentare in einem Issue, Ergebnisse kommen als Antwort zurück. Die Inhalte sind zusätzlich verschlüsselt. Details in docs/relay.md.

Sicherheit

Erweiterter Modus

Der Skript-Modus ist mächtig und gefährlich: er kann Dateien lesen/schreiben und Programme starten, soweit Blender das darf. Er ist standardmäßig freigabepflichtig und wird vollständig protokolliert. Nur einschalten, wenn du dem Agenten vertraust.

Gefahrenzone

Setzt alle Aufträge zurück, beendet das Vertrauensfenster und optional alle Agent-Schlüssel. Danach muss ein Agent neu autorisiert werden.

So funktioniert es

  1. Connector (dieses Fenster) spricht mit Blender über 127.0.0.1.
  2. Add-on führt Aktionen in Blenders Haupt-Thread aus und schickt Ergebnisse zurück.
  3. Agent ruft die API mit seinem Schlüssel auf, sieht den Werkzeugkatalog und bekommt JSON-Antworten plus Vorschaubilder.
  4. Riskante Aktionen bleiben hier stehen, bis du sie bestätigst.

Minimalbeispiel für einen Agenten

curl -s http://127.0.0.1:PORT/v1/tools \
  -H "Authorization: Bearer DEIN_SCHLUESSEL"

curl -s -X POST http://127.0.0.1:PORT/v1/jobs \
  -H "Authorization: Bearer DEIN_SCHLUESSEL" \
  -H "X-BB-Client: 1" -H "Content-Type: application/json" \
  -d '{"tool":"scene.info","params":{}}'

# Ergebnis abholen (wait=20 wartet bis zu 20 s)
curl -s "http://127.0.0.1:PORT/v1/jobs/JOB_ID?wait=20" \
  -H "Authorization: Bearer DEIN_SCHLUESSEL"

Wenn etwas klemmt

  • Blender nicht verbunden – Add-on aktiv? „Server starten“ geklickt? Port 9876 frei?
  • Token falsch – Token auf dem Reiter „Verbindung & Agent“ kopieren und im Add-on einfügen.
  • Keine Vorschaubilder – Blender braucht eine Kamera oder das Add-on legt eine temporäre an; prüfe den Job-Fehler im Verlauf.
  • Externer Zugang geht nicht – Netzwerk blockiert ausgehende Tunnel; nutze den Relay-Weg.

Grenzen (ehrlich)

  • Das Programm erkennt nicht automatisch, was „die Wange“ eines fremden Modells ist – du oder der Agent legt Bereiche an (Auswahl, Box, Kugel, Höhenband).
  • Nach starken Topologieänderungen können gespeicherte Bereiche veralten; das Add-on meldet das und bietet eine Reparatur an.
  • Eine Wiederherstellung ist nur so gut wie die letzte Sicherung.
